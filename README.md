# 针毡中国

把去过的地方、喜欢的照片和沿途故事，钉在一张可以慢慢探索的中国地图上。

这是「归途」旅行地图的公开代码版本。仓库仅包含代码与通用示例素材，不包含作者的私人旅行照片、已保存的记忆数据或线上站点的部署标识；它也不会自动连接作者的线上数据。

## 已实现

- 中国省级地图，以及可进入的省份、城市页面；支持缩放、拖动和隐藏照片。
- 给省份和城市更换封面照片；在城市里按景点或时间线浏览记忆。
- 为一段记忆上传多张照片、日期、景点、100 字以内的一句话总结和完整旅行感想。
- 照片墙与单张大图浏览；未写总结时，列表显示感想开头的完整短句。
- 旅行记忆和封面分别存储在 D1 数据库与 R2 对象存储中。

「足迹回放」尚未实现：当前不会记录 GPS 轨迹，也不会根据景点名称推测实际路线。世界地图、百度地图轨迹导入和原生 App 同样属于后续方向。

## 本地运行

需要 Node.js 22.13.0 或更新版本。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址即可预览。构建检查：

```bash
npm run build
```

项目使用 React、TypeScript、Vinext、Cloudflare Workers、D1、R2、Drizzle ORM 与 `cn-atlas` 地图数据。若要部署自己的版本，请配置自己的站点与存储资源；本仓库不附带作者的线上访问权限。

## 隐私说明

`public/demo/` 已被排除在此仓库之外。不要把私人照片、数据库导出、密钥或 `.env` 文件提交到公开仓库。网站界面中的通用示例内容不代表真实旅行记录。
